# Trollbound

Trollbound is a short, trap-filled 2D platformer built in **Godot 4** for the **Stardance Challenge**.

The goal is simple:

**Reach the exit.**

The problem?

The level doesn't want you to.

Platforms disappear, movement suddenly changes, safe-looking paths become traps, and sometimes the correct path isn't even visible.

## 🎮 About the Game

Trollbound is inspired by the game *Level Devil*

## 🕹️ Controls

1. Move left - Left Arrow key
2. Move right - Right Arrow key
3. Jump- Space Bar / Enter
